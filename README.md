## 📖 Overview

**Zaharat** is a TypeScript web application supporting a curriculum (منهج) overview.

## ✨ Features

- ✓ Curriculum navigation
- ✓ Responsive UI

## 🛠️ Tech Stack

TypeScript, Vite.

## 🚀 Getting Started

```bash
git clone https://github.com/tounektimohamed/Zaharat-.git
cd Zaharat-
npm install
npm run dev
```

> Open the dev server URL printed in your terminal.
